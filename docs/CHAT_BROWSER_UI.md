# 普通聊天界面与隐藏研究台

使用 <http://127.0.0.1:8000/>。修改后若浏览器保留旧页面，请刷新；不要直接打开 HTML 文件。

## 操作

- 默认是普通聊天：左侧历史对话、右侧消息。时间轴整列默认隐藏，顶部“显示时间轴”打开，点击“隐藏时间轴”或面板内“隐藏”关闭；收起后聊天区占用释放的宽度。左上角菜单按钮可收起历史，手机上是抽屉，点击遮罩或按 Escape 关闭。
- 点击“新对话”开始另一条会话。历史按更新时间排列，点击可恢复消息与引用；刷新或关闭后再打开仍可读取。
- **3 秒内连续点击左上角“心”Logo 5 次**进入研究台。少于 5 次、超时或点击其他位置不会打开。刷新后默认仍隐藏，不因为曾打开过就自动展示。
- 研究台包含病例、评测、模型/索引状态、模型补充开关和结构化追踪；“返回普通界面”将它们收起。技术状态仅在研究台展开时定时刷新。
- 引用只放在对应回答气泡内，连续的 `[1][2]` 显示为上标 `1、2`，避免看成 `12`；点击“查看 X 条引用”才展开原文、来源网址、日期和网络甄别提示。普通界面不展示内部推理。
- 消息正文支持 `**粗体**` 和 `** 带空格的粗体 **`；仅创建安全文本节点，不执行回答中的 HTML。用户气泡靠右，助手气泡靠左。聊天区、消息和输入区减少留白；输入框默认一行，输入多行时自动增高，清空后缩回。

## 本地不足时的网络补证

`network_mode=auto` 下，本地没有相关资料，或者只有 Huatuo/问答类等非权威候选时，服务端会强制尝试 PubMed 公开证据；模型规划器返回 `ready` 也不能跳过这条覆盖规则。网络结果会进入同一轮重排、回答和气泡内引用。网络引用标为“网络来源 · 需要甄别”，回答会追加 `【信息来源于网络，需要甄别】`，并在展开引用中提供来源网址。

如果 PubMed 无结果、工具未配置或网络失败，系统会如实标记工具状态并在证据不足时拒答，不把“查无记录”说成“没有问题”。`network_mode=off` 时不执行网络补证。网络搜索摘要不能直接成为引用，必须拿到正式摘要或正文；现有安全、脱敏、工具预算和急救短路规则继续生效。

## Cookie 各管各的

| 名称 | 用途 | 读取/清除方式 |
| --- | --- | --- |
| `hd_user` | 随机匿名浏览器身份，90 天有效 | 服务端签发，HttpOnly、SameSite=Strict，HTTPS 时 Secure；顶部“清除用户 Cookie”撤销并清除旧身份，再建立新身份 |
| `hd_research` | 研究台最近视图、评测 run_id；90 天有效 | 前端界面设置，不包含身份、对话或 API key；研究台里的“清除研究台 Cookie”单独删除 |

用户 Cookie 不直接装对话内容。服务端只保存身份凭证的哈希，历史放在 `data/runtime/browser-history.sqlite3`，按匿名身份隔离。聊天、附件作用域和历史访问使用服务端 Cookie 身份，不信任浏览器传来的任意 `user_id`。用户输入经过已有脱敏模块再写历史；使用临时附件的轮次只留占位，不把附件或派生回答变成长期历史。

清除用户 Cookie 会使旧身份立即失效，新身份不能读取原历史；正在结束的旧请求也不会重新登记历史。其他同源页面会收到提示并收起旧对话。此操作**不等于删除服务器记录**，也不会删除共享病例、研究台设置、模型 key 或语料。确认框明确说明这些边界。

清除研究台 Cookie 不撤销用户身份、不清空聊天历史。隐藏入口也不是管理员认证：这是本机 toy 的 UI 分层，不适合直接暴露公网。已有研究病例和管理 API 仍属于共享本地研究功能。

不同浏览器/浏览器配置文件得到不同身份；同一配置文件的普通标签页共享 Cookie。`localhost` 和 `127.0.0.1` 是不同主机，建议统一使用上面的地址。禁用 Cookie 时会明确提示，不会悄悄使用共享访客身份。

## 接口与验证

新增 `GET /api/v1/browser`、`DELETE /api/v1/browser`、`GET/POST /api/v1/browser/sessions`、`GET /api/v1/browser/sessions/{id}`。历史列表最多返回最近 200 个会话，每个会话恢复最近 100 轮，早期记录不因此删除。无 Cookie 的既有脚本 API 保持兼容，但不能冒用浏览器保留的身份/会话前缀。

```powershell
.\.venv-agentic\Scripts\python.exe -m pytest tests/test_browser_identity.py tests/test_api.py -q -p no:cacheprovider --basetemp=data/runtime/chat-browser-test-new
.\.venv-agentic\Scripts\python.exe -m scripts.verify_chat_ui
```

第二个命令启动临时存储的 Mock 应用，在真实 Chrome 中测试默认布局、五次点击、历史恢复、Cookie 分离和窄屏抽屉，并生成截图与报告到 `data/runtime/verification/chat-ui-<时间>/`。它不连接生产语料、不调用付费模型，也不停止后台向量构建或翻译任务。
